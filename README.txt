AFTERGLOW — early edition

Double-click Afterglow.html (or Start Afterglow.cmd) to open the app in your browser.
Chrome or Edge is recommended for audio sharing.

Open music or drop an audio file onto the window. Playback is local; nothing is uploaded.
Choose Neon rain, Deep space, or Abstract flow. Adjust motion, sensitivity, and palette.
Use the fullscreen button for an immersive scene. Escape exits fullscreen.
Space plays or pauses a loaded song. The scene's pause button controls animation separately.
Settings are saved locally when browser storage is available.

Connect shared audio opens the browser's sharing chooser. Select a source and enable audio.
Some source/browser combinations do not provide audio. If no audio track is available,
the app explains this and lets you use a local file instead. Disconnect ends sharing.
Shared sound is not replayed by Afterglow, avoiding echo.

This first version is a standalone browser app, not an installed Windows application
or a wallpaper behind desktop icons. No installation or internet connection is required.
Hidden-window pausing pauses scenery only; your music keeps playing.
